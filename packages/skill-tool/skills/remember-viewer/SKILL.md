---
name: remember-viewer
description: 识别值得跨场记住的观众自述，例如长期爱好、偏好和经历。
---

从观众自己的发言中找长期兴趣、偏好或经历。归到某位观众前，核对来源事件 ID 和平台身份。跳过转述、意思不明的玩笑、敏感细节和一时的感想。

用 `memory_search` 按观众 UID 先查已有记录，跳过重复项。有冲突时提示主播核对已有记录。

用 `memory_remember` 保存，传入 UID、简短记忆内容、逐字引文和来源 ID。主播明确要求记住一份记录时，可以引用当前主播消息并保留「主播提供」的来源；只有观众本人发言才称为观众自述。缺少来源或 UID 时，向主播说明缺少的信息。
